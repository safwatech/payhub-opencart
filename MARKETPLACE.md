## Long description

> Native OpenCart 4 payment extension that wires PayHub as a single
> gateway for Sadad / Moamalat / Mobicash / T-Lync / Adfali. Installs
> as an .ocmod zip via the Extension Installer; no Composer required.
> Includes admin config, webhook verification, OTP/QR/Lightbox flow
> renderers, and bilingual English/Arabic strings.

## Submission timeline

OpenCart reviews are typically 3–7 business days. The reviewer
spot-checks the .ocmod zip on a fresh OC4 install and verifies the
extension installs/enables/uninstalls cleanly.
